## 每份文档的验收项

- 原题号、题干、全部选项
- 答案/解析是否存在，以及是否初始隐藏
- 图片是否保留并内联
- 公式是否转成 MathML
- 代码缩进、代码块边界
- 表格、阅读材料、题内小问
- 生成页与源 Markdown 的题数/内容覆盖
- 失败时是否正确回退到确定性答题页

## 添加方式

每份文档使用一个目录：

```text
experiments/quiz-llm/inputs/<id>/
  source.md
  images/
  meta.json
```

`meta.json` 至少记录：

```json
{
  "source": "本地文件名",
  "sha256": "...",
  "questionCount": 0,
  "features": ["images", "formulas", "code", "tables", "ocr"]
}
```

先用 10–12 份跑一轮，确认题数和答案覆盖；再决定是否把这些输入纳入长期回归。
