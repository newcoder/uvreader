# 滚动模式（EPUB）几何与堆叠设计

> 状态：**已启用（默认开启）**。真机断言 31 条全绿（`npm run desktop:check-scroll`）；桌面 e2e 全绿（`npm run desktop:e2e`，含开关打开后的那一轮）。
> 这份文档记录的是「为什么会跳/会空白」的完整证据链，以及堆叠滚动的不变量与开启/回滚方式。

## 1. 目标

滚动模式下：

- 连续往下读：跨节**不跳**、不卡住、不空白；
- 往上回滚：同样连续，不滚进空白；
- **不能影响既有功能**：目录跳转、上一页/下一页按钮、翻页键、高亮/选区/位置记忆、分页模式。

## 2. 现象与证据（真机 Chromium + 书库真书《世说新语》，38 节）

三组实测数据（`debugGeometry` / `debugGeometryMore` 由补丁暴露，阴影根是 closed，外部读不到）：

| 场景 | container 盒子 | client | scrollHeight | `size`（视口高） |
| --- | --- | --- | --- | --- |
| 刚打开 | 900×**640** | 640 | 709 | **640** ✓ |
| 跳转后（旧实现） | 900×**2809** | 2809 | 5919 | **2809** ✗ |
| 一路读下去（旧实现） | 900×28374 | 28374 | 28374 | **28374** ✗ |

关键对照：一个普通 `overflow:auto` 盒子（内容 3000、盒子 640）→ `rect=642 / client=640 / scroll=3000` ✓
即：**滚动容器的 clientHeight 应当等于盒子高度（视口），scrollHeight 才是内容**。
旧实现里 `#container` 的**盒子本身**跟着内容长 ✗，于是 foliate 里所有以 `size`（视口高）为前提的判断全部失真 ✗。

## 3. 根因链（四条，逐条已修）

1. **容器盒子 = 内容高度**（网格按内容给尺寸）→ `size` 读成内容总高（28374 ✗ 而非 640 ✓）；
   → 页数、`atEnd`、上一页/下一页、滚动边缘判定全部建立在 `size` 上，因此**最初「一页结束就跳到下一页」**也是它的表现。
   → 修：滚动模式下 `:host([flow="scrolled"]) #container { position: absolute; inset: 0 }`（钉成视口大小）。
2. **占位用容器 `padding-top`** → 在 `overflow:auto` 盒子上 padding **会把盒子撑大** ✗（实测 `offsetHeight=2809` 全是那行 padding）→ 又把 `size` 污染回去。
   → 修：占位改成**独立 spacer 元素**（`#container` 的第一个子元素，`width:100%`，高度=已读部分的实测高度和）。
3. **占位允许估算**（未测过的节按平均值预留）→ 视口被推到内容之外 → **跳转后整屏空白**（实测 `jump#19 start=3110 extent=3110`）。
   → 修：占位**只允许实测高度**，未测过按 0。
4. **跳转/续读挂进来的节不会重新布局**（`#container` 的 ResizeObserver 只在**容器自身尺寸**变化时触发）→ 新节高度 0 ✗ → 空白 + 后续滚动卡死。
   → 修：`#display` 里挂载后**显式 `view.render(layout)`**；`viewSize` 在滚动模式**一律取容器 scrollHeight**（跳转后只剩 1 节时也要把 spacer 算进去）。
5. **前插与 spacer 让位不同步**（向上滚动时上方短暂空白，用户实测）：元素先插进来 ✗，而 spacer 要等**异步**加载完成后的 `#syncSpacer` 才收缩 ✗ → 中间几帧内容被顶下去再弹回。
   → 修：`#display` 里**先登记 + 立刻 `#syncSpacer()`，再 await 加载**（占位高度用实测值 ✓，1:1 换位 ✓）。
6. **到边缘才开始加载** → 向上滚到占位区时上一节还在加载 → 看到空白。
   → 修：滚动同步（`#afterScroll('scroll')`）里距上下边缘还有 **2 屏**就预挂相邻节（`eager-fill`），并在引擎侧**上下双向预取**；该逻辑**只由滚动同步触发且导航中不触发**（否则 `#afterScroll` 在 `#goTo` 内同步执行时会重入导航，把堆叠整塌成 1 节 —— 实测踩过 ✓）。

## 4. 修复后的不变量（= 回归断言的判据）

| # | 不变量 | 断言位置 |
| --- | --- | --- |
| 1 | `size` == 视口高度（640，而不是内容高度） | `debugGeometry`（真机脚本） |
| 2 | 跳转后：目标节**顶部就在视口里**、且下方仍有内容可滚（`extent ≥ start + size`） | `check-scroll-stack.mjs` |
| 3 | 跨节后**上一节仍挂着**（可平滑回滚） | 同上 |
| 4 | 续读/翻页**不把视口推到目标节开头之外**（keepPosition） | 同上 |
| 5 | 向上滚动会**填充占位**，不会滚进空白 | 同上 |
| 6 | 挂载窗口受限（≤ 当前 + 最近若干节），不会无限膨胀 | 同上 |
| 7 | **分页模式只挂一节**、跳章/上下页行为与优化前一致 | 同上 |
| 8 | 跳章会**清掉旧节的 DOM**（否则残留高度污染滚动范围） | 同上 |
| 9 | 占位只用实测高度（未测过按 0） | 代码约定 + 断言 2 |
| 10 | **前插瞬间可见内容不被顶走**（防向上空白） | `check-scroll-stack.mjs`（立刻测 vs 稳定后必须一致） |
| 11 | **提前填充只由滚动同步触发**（导航中不得重入） | 同上（跳章后旧窗口清空、以目标节为起点） |

## 5. 验证方式

- `npm run desktop:check-scroll`（Electron/Chromium 真机，**33 条**）：
  含堆叠场景、分页模式、目录跳转、上下页、向上回滚、**前插不位移（防上方空白）**；
- 真书脚本（临时用）：书库 `Books/示例书库/世说新语.epub` + `debugGeometry` 取证；
- 手工清单（重开堆叠后必做）：目录点章节、上一页/下一页、PageUp/PageDown/方向键、高亮显示与选区、关掉再开的位置记忆。

## 6. 开关与回滚

- 开关在打补丁的 `node_modules/foliate-js/paginator.js`：`#stacked = true`（**默认开启**）；
- 打补丁脚本：`patch-foliate-scroll.cjs`（64 处，每处有唯一标记，上游结构变了会**大声报错**并中止）；
- 回滚：`npm ci`（重新装依赖即还原）或把开关改回 `false` → `node patch-foliate-scroll.cjs` → `npm run desktop:build`；
- 回归：`npm run desktop:check-scroll`（31 条几何/堆叠/翻页）+ `npm run desktop:e2e`（应用级：打开/翻页/选词/高亮/笔记/书签/搜索/OCR/PDF/批注与恢复/导航）。

## 7. 已知限制 / 后续

- 刚开始读的**前几节**（挂载窗口未填满时）滑块尺寸会略变（此后由 spacer 撑住）；
- 只预留**上方**已读部分（不预留下方），以保证「滚到已挂载内容的底部」仍是有效判据（否则底部预留会让它永远不成立、滚轮再也触发不了续读）；
- 后续可选：把「上一页」也做成 keepPosition（现在到顶时会走正常翻页路径）。
