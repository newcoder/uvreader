# pdf_tool:选择题最后一个选项整行丢失(CSP2019 第 8 题 D)

日期:2026-10-21 · 提出方:reader(UV Reader / 纽扣)

## 现象

`CSP2019.pdf` 第 2 页第 8 题,PDF 上是:

```
8. 一棵二叉树如右图所示…则该数组的最大下标至少为（ ）。
   A. 6        B. 10        C. 15        D. 12
```

但 MinerU 的 `content_list.json` 里,这一题的 `text` 只到 `C. 15`:

```
"8. 一棵二叉树…（ ）。 A. 6 B. 10 C. 15"
```

Doc JSON / Markdown / HTML / 答题页都因此**没有 D**。不是家具清理(选项行已豁免),是提取阶段整段尾部被截断。

## 需求

1. **选择题选项完整性检查**:一个题目块里出现 `A./B./C.` 但缺 `D.`(或选项数少于 4)时,不要静默通过:
   - 尝试从原页面对该行/该块做一次定向 OCR 补回缺的选项;
   - 补不回来就在 audit 里给 warning(`question_options_incomplete`),并保留已识别部分。
2. **不要跨题拼接**:不要把下一题的选项补到上一题。
3. **验收**(`CSP2019.pdf`):
   - `content_list` 第 2 页第 8 题的选项为 A–D(`D. 12`);
   - 若无法补回,audit 明确报「第 8 题选项不完整」,下游可以提示用户。

## reader 侧

答题页只按原文/提取结果渲染;缺 D 时不会自己编造选项。上游补回后,重新生成答题页即可。
