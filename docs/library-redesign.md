# 书库页面重构设计(左右布局 + 导航树)

> 状态:**已实现**(本文件保留为设计与决策记录)。可交互预览:`docs/library-redesign-preview.html`(用浏览器打开,左侧树/折叠/标签筛选/网络搜书/标签编辑都可点)。

## 1. 目标

- 书库页改为**左右布局**:左侧可收缩导航树,右侧内容区。
- 树第一级两部分:**本地书库** 与 **网络搜书**。
- 本地书库为缺省节点,右侧显示全部书籍;点标签子节点显示该标签的书。
- 去掉页面顶部的「logo + 书库」标题区;搜索框移入**右侧内容区**。
- 现有能力保留:封面卡片、继续阅读、划线/笔记入口、右键菜单、拖拽导入、空状态、在线搜索/下载/登录。

## 3. 左侧导航树

| 节点 | 类型 | 点击行为 | 右侧显示 |
| --- | --- | --- | --- |
| **本地书库 (n)** | 根节点,可选中 | 选中;箭头展开/收起子节点 | 全部书籍 |
| ＋ 添加图书 | 动作 | 打开文件选择(可多选) | 不切换视图 |
| **标签** › 小说 (12) | 分组 + 子节点 | 选中 | 含该标签的书 |
| **阅读状态** › 正在阅读 (3) | 分组 + 子节点 | 选中 | 该状态的书 |
| **文件夹** › Books (20) | 分组 + 子节点 | 选中 | 该文件夹(含子文件夹)的书 |
| **网络搜书** | 根节点,可选中 | 选中 | 在线搜索视图 |

说明:

- **标签来源**:每本书的标签(`settings.bookTags`,在图书右键菜单/阅读笔记里维护),按名称排序、显示数量。没有任何标签时,「标签」分组下显示灰色提示(新增文案)。
- **阅读状态 / 文件夹 / 有划线**是现有筛选能力,建议保留为树内分组(见待确认 1);「有划线」作为阅读状态组内的一个节点(有划线 (n))。
- 根节点右侧显示总数;子节点右侧显示各自数量,数量用弱化色。
- 树只占左侧面板;窄窗口(<900px)默认收起,展开时以抽屉覆盖内容并带半透明遮罩。

## 4. 右侧内容区

### 4.1 工具条(两种视图共用)

- 左端:**导航按钮**(仅面板收起时显示)+ **搜索框**;搜索框占位符随视图切换:
  - 本地:`搜索图书…`(按书名过滤当前节点结果,不改选中)
  - 在线:`搜索可下载的书籍…`(输入 450ms 防抖后触发来源搜索)
- 右端:当前节点标题 + 数量(如 `本地书库 · 24 本`),弱化色;不做大标题。

### 4.2 本地视图

- 卡片网格沿用现状:封面(含封面适配按钮)、进度条、`n 处划线` / `笔记` 按钮、右键菜单、拖拽导入、`继续阅读` 行(仅"本地书库 + 未输入搜索"时)。
- 空状态沿用现状(暂无图书 → 添加图书 / 添加示例书)。
- 拖拽整页可用,拖入即导入。

### 4.3 网络搜书视图

- 完全沿用现有实现:结果行(勾选、来源、格式、大小、需登录/可下载/下载中/打开)、底部「全选 / 下载所选」条、登录窗口链路、下载完成后切回本地自动刷新。
- 切换节点不重建视图:在线结果与下载进度在往返切换时保留(沿用双网格方案)。

## 5. 交互细节

- **默认与记忆**:打开时恢复上次节点(`settings.libCategory` 复用为节点 id;默认 `all` = 本地书库);网络搜书节点单独记忆。
- **折叠**:面板右上 `⟨` 收起;记忆到 `settings.libNavCollapsed`;动画 160ms;折叠后工具条出现 `☰`(navigator 图标)重新展开。
- **键盘**:树节点为 `button`;Enter/Space 选中,↑/↓ 移动焦点,←/→ 收起/展开分组。
- **搜索**:本地即时过滤;在线防抖 450ms,与现状一致。
- **下载完成**:沿用 `_libStale`,回到本地节点时刷新卡片。

## 8. 标签流程设计(导入 / 下载 / 主页打开)

### 8.1 现状

- 标签存于 `settings.bookTags[bookPath]`,已有编辑入口:书籍设置(书籍菜单)与「新建阅读笔记」弹窗(分类输入 + 已有标签 datalist);写入走 `plugin.setBookTags()`。
- 本地导入:`_importBooks` 复制进书库目录,完成后只有一条 Notice「已添加 n 本」。
- 网络下载:写入 `Books/下载`,完成后 Notice + 「打开」按钮。
- 主页「打开书籍…」:直接打开任意路径(书库外的也能打开,host-shim 的 resolve 接受绝对路径),但**不进入书库、没有标签**。

### 8.2 目标(已确认)

- 新书进库(下载 / 导入 / 主页打开的外部书)**自动打标**,无需询问、不打断阅读。
- 标签可随时修改:书籍右键菜单 →「标签…」重新选择。
- **来源名(如 Z-Library)不作为标签**。

### 8.3 自动打标规则

| 时机 | 自动标签 |
| --- | --- |
| 网络下载完成(单/批量) | `下载` |
| 本地导入(选择文件 / 拖拽) | `导入` |
| 主页打开书库外的书(复制入库) | `导入` |
| 主页打开书库内的书 | 不打标,直接打开 |

- 自动标签是普通标签,之后可在右键菜单里改。
- 与已有标签**合并**(不覆盖):重复导入同一本书时保留用户原有标签。
- 完成后给一条轻提示:`已加入书库 · 已打标签「下载」`(可点击打开),不弹对话框。

### 8.4 标签编辑(书籍右键菜单)

右键菜单新增「标签…」,打开轻量编辑浮层:

```text
┌────────────────────────────────────────────┐
│ 标签 · 世说新语                             │
│ [小说] [历史] [古籍] [导入] [＋ 新建]       │
│ 也可以输入新标签: [____________]            │
│                        [取消]   [保存]      │
└────────────────────────────────────────────┘
```

- 已有标签 chips 多选(含自动标签,可取消);输入框支持逗号/分号/换行(复用 `parseBookTags`)。
- 批量编辑(多选书籍时)?暂不做,先按单本。
- 菜单项同时出现在书库卡片右键菜单与阅读器内的书籍菜单(`addBookFileMenu` 路径)。

### 8.5 主页「打开书籍」→ 复制进书库

- 书库外的文件:**直接复制到书库**(重名沿用 `_freeBookPath` 规则)→ 自动打标 `导入` → 打开;用现有的打开遮罩提示「正在加入书库…」。
- 书库内的文件:直接打开,不复制、不打标。
- 复制失败(磁盘满/无权限)时提示原因并回退为「仅本次打开」。

### 8.6 数据与实现映射

- 自动标签常量:`AUTO_TAGS = { download: "下载", import: "导入" }`(library-data.js 导出,可单测)。
- 合并逻辑:`mergeBookTags(existing, added)` 纯函数 + `plugin.setBookTags()`(新增或合并)。
- 新组件 `tag-editor.js`:宿主无关轻量弹层,复用 `parseBookTags`;接收 `(file, currentTags, allTags, onSave)`。
- 接入点:
  - `library-modal.js`:`_importBooks` 末尾打「导入」;`_startOnlineDownload` 成功分支打「下载」(批量逐本成功即打,无需汇总弹层)。
  - `book-notes.js` 的 `addBookFileMenu`:新增「标签…」菜单项(书库与阅读器共用);书库传入 `onTagsChanged` 以便编辑后重建树与卡片。
  - `apps/desktop/src/renderer/entry.js` `openBook`:书库外 → `plugin.importBookToLibrary()` 复制入库 + 自动打标 → 打开;同一外部路径再次打开复用已有副本(`settings.importedBooks` 记录来源→入库路径)。
- i18n 新键(9 语言 + check:i18n,实际清单见 §7)。
